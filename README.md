## Kairo Linux

Kairo Linux é uma distribuição Linux leve criada para oferecer desempenho, simplicidade e controle. O projeto foi desenvolvido como uma base Linux otimizada, focada em rodar bem até em dispositivos com recursos limitados.

## 🚀 Sobre

O Kairo Linux busca entregar uma experiência Linux enxuta, removendo componentes desnecessários e mantendo apenas o essencial para um sistema rápido e personalizável.

Principais objetivos:

- ⚡ Baixo consumo de recursos
- 🪶 Sistema leve e rápido
- 🔧 Fácil personalização
- 📦 Base do debian
- 💻 Compatibilidade com diferentes arquitetura

## ✨ Recursos

- Rootfs personalizado
- Sistema de build próprio
- Estrutura preparada para imagens ISO
- Otimizações para hardware limitado
- Ambiente simples e adaptável

## 🏗️ Build do sistema

O Kairo Linux possui ferramentas próprias para construir o sistema:

```build
git clone https://github.com/davizintech-ops/Kairo-Linux.git
cd Kairo-Linux
./build.sh
```
